## Project Description
This project demonstrates a basic DevOps pipeline for a simple Python application (`hello.py`). 

The pipeline includes:
* **Git & GitHub** for version control.
* **Bash Scripting** (`sysinfo.sh`).
* **Docker** for containerization.
* **GitHub Actions** for Continuous Integration (building and pushing the Docker image to Docker Hub).
* **Nomad** for deployment specification (`hello.nomad`).
* **Loki/Grafana** for log monitoring documentation.
